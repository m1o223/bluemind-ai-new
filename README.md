# BlueMind AI Backend

Clean backend foundation for authentication, AI chat, memory, reminders, and streaming.

## Setup

1. Copy `.env.example` to `.env`.
2. Add real values for `MONGODB_URI`, `JWT_SECRET`, and `OPENAI_API_KEY`.
3. Install dependencies with `npm install`.
4. Run development server with `npm run dev`.

## API Base

Default base URL:

```txt
https://your-render-backend-domain.onrender.com/api
```
